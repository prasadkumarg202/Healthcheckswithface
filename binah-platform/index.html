Developer Architecture

Integrate the Binah SDK in Minutes

Delivered as native SDKs for iOS, Android, Flutter, React Native, and WebAssembly (WASM), Binah.ai integrates into your existing patient portal or mobile health application.

100% On-Device Processing

Video frames are processed directly inside the client device memory. No video or biometric facial imagery ever leaves the phone.

BinahSDK_Integration.ts 
import { BinahSession, HealthMonitor } from '@binah/sdk';

// 1. Initialize Binah Enterprise Session
const session = await BinahSession.create({
  licenseKey: process.env.BINAH_ENTERPRISE_KEY,
  processingMode: 'DEVICE_ONLY',
  measurementDuration: 45 // seconds
});

// 2. Start Video-Based Face Scan
const stream = await navigator.mediaDevices.getUserMedia({ video: true });
session.startMeasurement(stream, {
  onVitalSign: (metric) => {
    console.log(`HR: ${metric.pulseRate} BPM | SpO2: ${metric.oxygen}%`);
  },
  onComplete: (report) => {
    console.log('Blood Pressure:', report.bloodPressure);
    console.log('ASCVD 10-Yr Risk:', report.ascvdRisk);
  }
});
